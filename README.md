# Сылу 🇰🇿

Мобильное приложение для изучения казахского языка через историю, культуру и символы страны.

> *Сылу тіл* — «красивый язык»

## О проекте

Язык учится легче, когда за ним стоит история. В «Сылу» уроки связаны с гимном, флагом, Абаем, Наурызом, домброй, юртой и пословицами.

**Для кого:** тех, кто хочет выучить казахский с нуля (уровни A1 → B1).

## Возможности (план)

- Уроки по уровням A1, A2, B1
- Карточки слов с озвучкой
- Упражнения: выбор перевода, сопоставление, сборка предложений
- Прогресс, XP, серия дней
- Ранги: Ауыл → Батыр → Хан
- Слово дня и пословица дня
- Викторины по истории и культуре

## Стек

- Flutter (Android и iOS)
- Hive / SQLite для локальных данных
- Контент уроков в JSON
